# Bank-term-deposit-campaign-response-prediction
 Banking Campaign Response Prediction and Contact Prioritization  of people

PS: Predict whether a customer will subscribe to a term deposit following a banking campaign. Estimate response probabilities from customer and campaign attributes, compare models, and prioritize customers when the number of available calls is limited. Analyze the trade-off between contacting more customers and achieving a higher response rate.

Dataset link: https://archive.ics.uci.edu/dataset/222/bank+marketing 

Expected output: Provide a response classifier, ranked prospective-customer list, precision-at-budget and simulated campaign outcomes, and a dashboard comparing targeted outreach with baseline strategies.
